# Identity Atlas support

Identity Atlas is a community project maintained by Control Alt Delete Tech Bits.

## Where to ask

Use a GitHub issue for:

1. A reproducible product bug.
2. A focused feature request.
3. Installation or documentation problems.
4. Browser compatibility or accessibility problems.

Search existing issues before opening a new one. Use the supplied issue form and remove all live tenant information from logs and screenshots.

For a private general enquiry, email Mark@controlaltdeletetechbits.co.uk.

For a suspected vulnerability, follow `SECURITY.md`. Do not open a public issue.

## Support boundary

Support is provided on a reasonable-effort basis and has no guaranteed response time. Identity Atlas does not include support for:

1. Microsoft Entra ID service incidents.
2. Microsoft Graph consent decisions for your organisation.
3. Recovery of deleted or changed tenant objects.
4. Review of complete live tenant reports.
5. Custom deployments that expose the local report server to a network.

Microsoft product support should be requested through the appropriate Microsoft support channel.

## Information safe to provide

You may provide:

1. Identity Atlas version.
2. PowerShell version.
3. Operating system version.
4. The affected command.
5. A redacted error message.
6. Whether report coverage was complete or partial.
7. Steps that reproduce the behaviour without tenant data.

Do not provide credentials, tenant identifiers, user details, object identifiers or generated reports.
